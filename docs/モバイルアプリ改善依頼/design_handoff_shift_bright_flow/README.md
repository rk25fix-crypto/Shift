# Handoff: Shift ― 明るいUIと「迷わない」導線の作り直し

## 概要

シフト管理SaaS「Shift」（Next.js 16 + Tailwind + Cloudflare Workers/D1 + Better Auth）のモバイルUIを、次の3つの指摘に応えて作り直したもの。

1. 全体的に暗い（`app/globals.css` が `prefers-color-scheme: dark` に自動追従するため、OSがダークだと真っ黒になる）
2. 利用開始までの登録の手間が多すぎる（事業所名→OTP→シフト種別を1件ずつフル入力→スタッフを1人ずつフォーム入力）
3. タブ移動が多い（`今日 / スタッフ / 週表示 / 交代 / 設定` の5タブ。今日と週表示が分かれている）

主な変更点：

- OS追従のダークモードを廃止し、暖色の白（#FFFDF8）を基調とした明るい固定テーマにする
- 初回セットアップを「業種を選ぶ → 勤務の確認 → 名前だけ入力」の3ステップにし、シフト種別は業種から自動生成、詳細はスタッフ本人に招待リンクで入力してもらう
- 下タブを5→3（`ホーム / スタッフ / 設定`）に減らし、`今日` と `週表示` を1画面（日付バー付きホーム）に統合
- 週グリッドの横スクロールを廃止し、7日を390px幅に収める

## このバンドルのファイルについて

同梱の `Shift 明るく迷わない.dc.html` は **HTMLで作られたデザインリファレンス**です。見た目と挙動を示すプロトタイプであって、そのまま本番に貼り付けるコードではありません。

作業は、このHTMLデザインを**既存コードベースの環境（Next.js App Router + React + Tailwind CSS v4）の作法で再実装する**ことです。既存の `components/` 配下のコンポーネント構成、Server Actions、`lib/` のクエリ層はそのまま活かし、表示層だけを差し替えてください。プロトタイプ内のインラインスタイルはTailwindのユーティリティに置き換えます。

ブラウザで開くとそのまま全画面が確認できます。1a・1b・1c・2c・2f・2i は実際にタップして動きます。

## 忠実度

**ハイファイ（hifi）** です。色・タイポグラフィ・余白・角丸は最終値です。ピクセル単位で再現してください。

例外：
- アイコンはすべて**プレースホルダー**（単色の四角・丸）です。実装時は既存のアイコンセットまたは新規に選定したものに差し替えてください。形状と寸法だけ守れば十分です。
- 料金（月2,980円／年29,800円／30人まで）は**仮の数字**です。確定値に差し替えてください。
- 通知・コピーの文面は確定値として扱ってかまいません。

## 実装の順序（推奨）

1. `app/globals.css` の `@media (prefers-color-scheme: dark)` ブロックを削除し、`--background: #FFFDF8` `--foreground: #2B2722` に。フォントを Zen Maru Gothic / Noto Sans JP に差し替え（`app/layout.tsx`）
2. `components/ui/BottomNav.tsx` を3タブに。`/week` を `/today` に統合し、`/swaps` と `/settings/*` の導線を移す
3. `DayList` に日付バーを足してホーム化、`AssignShiftSheet` を2列グリッドに
4. `WeekGrid` の横スクロール廃止
5. 業種プリセットとオンボーディング（1a）
6. 招待リンク（2i）とスタッフ本人画面（1c）― 新規。Better Auth のトークン付きリンクが必要
7. 状態画面（3a〜3f）

1〜4だけでも「暗い」「タブが多い」は解消します。5〜6が「登録の手間」への回答です。

## アクセシビリティ

- 11〜12pxの文字には `#6E665C` より薄い色を使わないこと（`#8B8176` `#9A9186` は4.5:1を下回るため不採用）
- `#C4601F` の上は必ず `#FFFFFF`（4.9:1）。`#FFF0E2` の上は `#A8511A`
- 色だけで情報を伝えない（休みは色＋「休」の文字、警告は色＋文言）
- タップ領域は最小44px

## アセット

画像・アイコンは**一切含まれていません**。プロトタイプ内の四角・丸はすべてプレースホルダーです。フォントはGoogle Fontsから読み込んでいます（Zen Maru Gothic、Noto Sans JP）。
